# 策略研究工程台设计（原 AI 工作台重构）

## 为什么
以一个研究项目连接需求、设计、开发、调试、实验、验证与交易计划。用户通过持续对话推动流程，直接操作文档、图表和编辑器；后台协作仅呈现任务状态和可核查产物。

## 信息架构
唯一主入口 core-05-ai-workspace-prototype.html。左侧为项目切换、研究阶段与数据/股票池/策略库；中间为助手对话、任务卡片与输入；右侧为产物标签和工作区。顶部展示项目与版本、演示范围。支持产物专注模式；1100 宽下可展开工作区再返回对话。
原 core-03 变为兼容导向：data→data、pool→pool、develop→develop、research/compare→experiments、plan→plan。兼容页不维护第二份业务状态。

## 对话与任务
快捷提示覆盖生成需求、设计、代码、实验、验证、交易计划和概念解释。自由输入按明确的演示意图识别；不能理解的输入显示能力边界并提供动作选择，不伪造通用模型回复。研究目标经对话转为待确认草稿，用户可直接编辑；对话卡片打开对应产物。
所有修改当前确认规格的动作都生成新版本。代码修复先展示旧/新差异，点击应用后检查并保存。后台任务具备执行中、已取消、失败、完成状态；提供取消、重试及一次失败模拟供交互检查。原型无模型联网请求。

## 产物与联动
需求：正文、验收标准、投入比例、成交额阈值，可编辑、确认、查看历史。
设计：维护说明和参数；流程图与时序图由共同节点结构生成；点选节点查看输入输出及对应源码行。确认新设计使代码旧引用过期。
开发：源码编辑、预置示例识别、不可变版本、修复差异、保存与运行。代码编辑不改变已保存版本。
调试：选择实验、事件表、节点筛选、单步与播放暂停，冻结源码定位；回放不冒称实时断点调试。
回测实验：账户指标、最近两次曲线、冻结清单、事件分歧和 JSON 导出。
验证：逐项展示演示检查证据；正式验证的真实数据、样本外、稳健性为未运行。当前版本或资源改变后报告过期。
交易计划：独立数据/账户输入、生成草稿、核对、确认导出；计划与回测概念解释常驻。
数据：合成快照覆盖、质量说明、模拟更新；股票池：搜索、流动性筛选、保存规则；策略库：浏览当前项目不可变版本并载入研究。

## 视觉与可访问性
背景 #08090c，面板深灰半透明、细边框和顶部高光；靛蓝/淡紫仅作为强调。阅读、代码区域采用实色深底；图形为离线 SVG。文字状态不只依赖颜色，键盘焦点清晰，尊重减少动态效果设置。1440×1000 与 1100×900 可操作，无页面水平溢出。

## 概念辨析
调试排查实现正确性；回测是历史模拟；策略验证汇总正确性、样本外与稳健性证据；交易计划核对最新账户与具体调整约束。反复在历史日期生成并模拟执行计划属于策略回测，核对下一份计划不属于回测。

## 本轮边界
离线单文件、内存会话刷新重置、预设对话和固定合成计算；不执行任意 Python、不连接真实多智能体或行情、不自动下单。可下载文档、源码、实验与演示计划。HTML 为后续 Rust GUI 设计参考，无生产 API 或数据库变更。浏览器检查只记录在变更目录，不能作为生产验收通过。
