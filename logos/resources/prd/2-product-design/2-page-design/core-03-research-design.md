# 高保真桌面原型设计

## 高保真桌面交互原型
用户要求提高GUI原型真实度；在S11～S16页面范围内提供 `core-03-research-prototype.html`。这是单文件离线HTML设计产物，最终应用仍使用Rust egui/eframe，不将HTML作为生产前端。

### 视觉规范
采用浅色内容区、深色导航、蓝绿色主色与细线边框，数字等宽；沿用已确认浅色默认方案。使用原生SVG图表和图标，不依赖外部字体、图片或CDN。桌面主视口1440×1000，兼容1100宽度；窄屏允许导航收起和内容纵向排列。

### 可操作范围
六页切换（包含策略开发）；股票池搜索、市场筛选、流动性过滤、行详情与保存反馈；策略模板、调仓和持仓参数可编辑；演示任务可运行、查看进度、取消并更新模拟曲线；比较页展示多曲线和区间；数据页演示更新并保存快照；计划页编辑手工持仓、生成参考差额并导出带演示标识的CSV；支持浅深主题与帮助说明。
每页固定标明“交互原型·演示数据”。数据在本地内存中，不联网、不读取用户真实行情、不执行真实回测、不下单。刷新重置演示状态，按钮反馈不得暗示已保存到生产数据库。

### 原型检查用例
| ID | 操作 | 预期 |
|---|---|---|
| UI-P01 | 打开并切换六页 | 页面标题、导航选中和对应内容一致，无脚本错误 |
| UI-P02 | 搜索股票、提高成交额阈值、选择股票 | 列表变化，空结果有说明，侧栏展示选中行 |
| UI-P03 | 修改参数并运行演示，随后取消 | 进度可见、按钮状态变化；取消不产生成功记录 |
| UI-P04 | 完成一次演示运行 | 曲线和记录更新，始终标注演示而非真实回测 |
| UI-P05 | 编辑持仓后生成计划并导出 | 股数差额更新，CSV含演示标识与版本日期 |
| UI-P06 | 切换主题并在1100和1440宽度查看 | 页面无横向溢出，文字可读，图表与表格可操作 |
这些是原型交互检查，不替代46项业务UT/ST及Windows/Linux原生GUI验收。检查结果单独存放在提案目录，禁止写成真实交易引擎通过记录。
