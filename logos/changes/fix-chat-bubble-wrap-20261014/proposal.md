# 变更提案：对话用户气泡排版修复（长消息不换行越界）

## 变更原因

issue #40 的残留症状：本地启动后，实验页（及任意路由）画布上出现一条深色单行横带，内容为需求草稿文本，压盖画布并探入右侧对话栏。经 fix-issues-40-41-20261013 修复（路由画布状态隔离）后症状仍在，说明原根因判断不完整。

本轮确诊真正根因：**右侧对话栏用户消息气泡的排版缺陷**，与画布状态无关——

1. 截图右栏消息序列可见：「你」标签 → 横带 → 助手回复，横带正是用户自己发送的长消息（内容为草稿默认文本）的气泡；
2. `render_message` 用户分支（`crates/research-desktop/src/app.rs`）使用 `Layout::right_to_left(Align::Min)` 布局气泡，内部 `ui.set_max_width(ui.available_width().min(360.0))`——right_to_left 布局下游标从右缘起步，初始 `available_width()` 约为 0，`.min(360.0)` 得到约 0，等于不设换行宽度，galley 不换行，单行向左无限延伸，越过右栏边界压到画布上；
3. 该缺陷与路由无关（对话栏跨路由共享），解释了为什么 id_salt 隔离修复无效、为什么无头遍历 11 个路由复现不了（复现脚本未注入长用户消息）；
4. 短消息无需换行不触发，草稿长度（约 76 字）才撑破。

## 变更概述

修复右侧对话栏用户消息气泡的换行与对齐：用户气泡不再使用 `right_to_left` 布局内依赖 `available_width()` 的方式限宽，改为 `top_down(Align::Max)` 右对齐布局，换行宽度取 `min(360, 对话栏实际可用宽)` 并显式启用文本换行，确保长消息在对话栏内折行显示、气泡不越出右栏边界；「你」meta 标签同步改为 Align::Max 右对齐（视觉不变）。

同时在设计文档补充对话气泡排版约束（禁止在 right_to_left 布局内依赖 available_width 计算换行宽度），并新增无头渲染回归用例 UT-S15-14：注入约 76 字用户消息，断言该消息 galley 折行为多行、左缘不越过对话栏左边界、右缘不越过窗口右缘——真实复现本缺陷，防止回归。
