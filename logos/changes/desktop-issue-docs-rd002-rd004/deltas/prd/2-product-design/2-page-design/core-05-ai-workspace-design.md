## ADDED — 演示原型与生产桌面映射

本 HTML 原型为演示交互设计（合成数据、内存会话），生产桌面 `crates/research-desktop` 以研究协调器协议为真实接口。二者在多数页面同构，但**数据中心与股票池两页存在有意分叉**（RD-004）：

| 页面 | 原型（演示交互） | 生产桌面（协调器协议 UI） | 验收对齐基准 |
|---|---|---|---|
| 数据中心 `#data` | 「当前合成数据快照」KV + 「价格与信号样本」fixture 表 + 「模拟更新快照」 | 「数据导入」（CSV 路径 + 价格口径）+ 「快照清单」（协调器 snapshot 列表）；通达信 / TickFlow 为后续生产能力 | 不对 HTML 像素对齐；以 S11 数据快照契约与场景测试为准 |
| 股票池 `#pool` | 搜索框 + 市场 select + 最低成交额 + 「保存股票池规则」+ 候选样本表 | RuleAST JSON 编辑 + as_of / 严格模式 / 固定成员 + 「预览」（协调器任务）+ 预览结果列表 | 不对 HTML 像素对齐；以 S12 股票池筛选契约与场景测试为准 |

分叉理由：原型资源页用于演示筛选交互概念；生产桌面直接暴露协调器真实能力（导入、预览任务），回退为演示壳会丢失生产价值。若未来需要将演示筛选 UI 映射到协调器 RuleAST，须单独立变更提案。除上述两页外，其余页面验收仍以本原型为视觉与信息架构权威。
