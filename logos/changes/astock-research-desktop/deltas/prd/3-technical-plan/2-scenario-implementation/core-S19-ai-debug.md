# S19 调试到实验比较

## 实验、事件与验证

```mermaid
sequenceDiagram
    actor U as 用户
    participant G as 统一工作区
    participant P as 项目状态
    participant W as 演示计算器
    U->>G: 启动当前冻结版本实验
    G->>P: 校验上游并冻结输入
    G->>W: 提交合成样本模拟任务
    W->>G: 返回事件、账户与净值
    G->>P: 保存实验与事件证据
    U->>G: 筛选、单步并定位事件源码
    U->>G: 生成验证报告
    G->>P: 关联当前版本实验与检查证据
    G->>U: 分别展示演示检查和正式验证结论
```

取消或模拟失败不增加实验；可重试。原始版本资金拒绝，修复版本默认收益6.25%。正式验证缺少真实数据、样本外和稳健性证据，不能显示通过。历史实验冻结输入不随修改变化。

本地原型动作不构成生产 API。正式接口须由后续运行时时序推导；本次无 API、DB、部署变更。对应检查见 core-S19-test-cases.md。
