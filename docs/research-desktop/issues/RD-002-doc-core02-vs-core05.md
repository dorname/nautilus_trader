# RD-002 core-02 与 core-05 设计口径冲突

- **类型**：文档不一致
- **优先级**：P1
- **状态**：open
- **权威实现现状**：对齐 **core-05**（黑色玻璃态统一工作台），而非 core-02 线框

## 冲突对照

| 主题 | `core-02-research-pages.md` | `core-05-ai-workspace-design.md` + 原型 HTML | `crates/research-desktop` |
|------|-----------------------------|---------------------------------------------|---------------------------|
| 主题 | **默认浅色，支持深色** | 「纯黑科技 v3」深色玻璃 | 仅深色（`theme::apply` 固定 `dark_mode = true`） |
| 默认窗口 | 1440×900 | 可操作基准 **1440×1000** 与 1100×900 | 1440×900 / 最小 1100×720 |
| 侧栏宽 | 180 逻辑像素 | 212（≤1200→178）；≤900 图标栏 65 | 212/178；**无 ≤900 图标栏** |
| 顶栏 | 56px（工作区/快照/数据日期） | 65px（面包屑 + 演示环境） | 65px |
| 底栏 | 32px 任务状态 | 28px footer 溯源声明 | 28px footer |
| 信息架构 | 五页线框（数据/池/策略研究/回测对比/计划） | 11 路由统一工作台 + 右对话栏 | 11 路由 + 对话栏 |

`core-03-research-design.md` 已声明「原六页能力迁入 core-05」，但 **core-02 正文未降级为历史附录**，仍可读作现行规格，造成验收歧义。

## 期望

1. 明确标注：**现行 UI 权威规格 = core-05**；core-02 标为「历史线框 / 已由 core-05 取代」或改写为与 core-05 一致。
2. 窗口尺寸、侧栏断点、主题策略三处数字统一到单一来源（建议以原型 CSS + `layout.rs` / `theme.rs` 常量为准）。
3. 若仍要求浅色主题，单独立变更提案；否则从 core-02 删除「默认浅色」。

## 建议修复方向

- 文档变更提案：修订 core-02，或拆为「archived wireframe」+ 指向 core-05。
- 同步 `logos-project.yaml` 资源描述，避免 AI/验收再读到冲突口径。
