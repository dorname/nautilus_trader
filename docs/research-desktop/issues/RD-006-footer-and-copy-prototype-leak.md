# RD-006 原生桌面页脚/文案仍泄漏「HTML 原型」语义

- **类型**：文案 / 产品诚实性
- **优先级**：P3
- **状态**：fixed（2026-10-05，提案 desktop-issue-fixes-rd003-rd006）

## 现象

原生 footer（`app.rs::render_footer`）原文：

```text
● 本地原型 · 合成样本 SYN-202601 · 刷新重置，可导出产物
```

该句直接拷贝自 HTML 原型 footer。对 **Rust 原生桌面** 而言：

- 「本地原型」易被理解为「仍只是 HTML 原型」，削弱生产桌面定位；
- 「刷新重置」是浏览器刷新语义，原生应用关闭/重开行为不同（工作区 SQLite 持久化）。

对话区 disclaimer「离线预设交互 · 计算来自合成样本 · 未接入模型」对演示边界仍合理，可保留。

## 期望

- 页脚改为例如：「● 本地研究桌面 · 合成/导入样本可追溯 · 结果绑定版本与快照」。
- 若某构建仍是演示包，用显式 tag「演示构建」而非「原型」。

## 建议修复方向

小文案变更即可；可并入下一轮 desktop 文案/保真提案。
