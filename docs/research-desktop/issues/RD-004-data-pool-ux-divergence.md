# RD-004 数据中心 / 股票池与原型信息架构不一致

- **类型**：UI / 产品
- **优先级**：P2
- **状态**：fixed（2026-10-05，提案 desktop-issue-docs-rd002-rd004——采纳方案 2「声明分叉」，已写入 core-05「演示原型与生产桌面映射」章节）
- **说明**：可能是「生产对接」有意偏离演示原型，但当前无文档声明「原型仅演示、桌面为协调器真接口」，验收时易判为 UI 不合格。

## 数据中心

| 能力 | 原型 `#data` | Rust `render_data` |
|------|--------------|-------------------|
| 主面板 | 「当前合成数据快照」KV（快照编号 / 覆盖 / 质量 / 复权 / 来源） | 「数据导入」：多行 CSV 路径 + 价格口径 radio + 导入按钮 |
| 次面板 | 「价格与信号样本」表格（合成 fixture） | 「快照清单」协调器返回的 snapshot 列表 |
| 主 CTA | 「模拟更新快照」 | 「导入」 |
| 边界文案 | 通达信 / TickFlow 属后续生产能力 | 真实导入路径（依赖 bridge） |

原型 a11y 证据（本地 `http://127.0.0.1:8766/...#data`）：存在「模拟更新快照」「当前合成数据快照」「价格与信号样本」标题。

## 股票池

| 能力 | 原型 `#pool` | Rust `render_pool` |
|------|--------------|-------------------|
| 筛选 | 搜索框 + 市场 select（全部/沪/深）+ 最低成交额 | **RuleAST JSON** 多行编辑 |
| 额外 | — | as_of、严格模式、固定成员 checkbox |
| 主 CTA | 「保存股票池规则」 | 「预览」→ 协调器任务 |
| 列表 | 候选样本表（代码/市场/成交额/入选原因） | 预览结果（协调器协议驱动） |

原型 a11y 证据：`搜索股票`、`市场筛选`、`最低成交额（万元）`、`保存股票池规则`、`候选样本`。

## 期望

任选其一并写进规格：

1. **对齐原型**：桌面提供与 HTML 同构的演示筛选 UI，底层再映射到协调器；或
